# CareBot AI

CareBot AI is a health awareness and assistance platform developed to help users access basic health information through a simple and interactive interface. The application brings together health-related features such as disease information, symptom-based prediction, prevention guidance, vaccination details, nearby hospitals, and public health updates in one platform.

## Features

* **AI Health Chatbot** – Provides information about diseases, symptoms, and prevention.
* **Disease Prediction** – Uses a machine learning model to provide a possible prediction based on entered symptoms.
* **Prevention** – Displays preventive measures and basic health guidance.
* **Nearby Hospitals** – Helps users find hospital information based on their location or selected city.
* **Vaccination** – Provides useful information related to vaccinations.
* **Health History** – Allows users to keep track of their previous interactions and predictions.
* **Public Health Updates** – Displays health-related updates and information.
* **Feedback** – Allows users to share their experience with the application.
* **User Authentication** – Provides separate sign-in and sign-up functionality.

## How It Works

The user can create an account and access the CareBot dashboard. From the dashboard, different health-related services can be selected based on the user's needs. Users can interact with the chatbot, enter symptoms for prediction, view prevention information, check vaccination details, and find nearby hospitals.

The frontend handles the user interface and interaction, while the backend manages the application logic and machine learning functionality.

## Purpose

The project was developed as an academic and practical application to explore how artificial intelligence, machine learning, and web technologies can be combined to build a user-friendly health assistance platform.

## Disclaimer

CareBot AI is developed for educational and informational purposes. The information and predictions provided by the application should not be considered a replacement for professional medical advice, diagnosis, or treatment.
